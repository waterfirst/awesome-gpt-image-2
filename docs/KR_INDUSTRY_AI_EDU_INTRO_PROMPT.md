# 제조업 특화 AI 교육 강의 인트로 이미지 프롬프트 (GPT Image 2)

아래 프롬프트는 **강의 오프닝 슬라이드(16:9)** 용으로 설계되었습니다.

## 1) GitHub 스타일 메인 프롬프트 (복붙용)

```text
Create a premium keynote intro cover image for an AI training lecture in Korean, focused on industrial sectors: manufacturing, semiconductors, display, and secondary battery.

Design goals:
- Tone: trustworthy, futuristic, executive-level education
- Aspect ratio: 16:9, presentation hero image
- Composition: wide cinematic layout with strong visual hierarchy
- Color palette: deep navy, cobalt blue, cyan accents, subtle silver highlights
- Lighting: clean studio glow + volumetric light streaks
- Style: realistic 3D + infographic-inspired HUD overlays, no cartoon look

Core visual elements:
- Left to right flow showing industrial transformation with AI
- Smart factory scene with robotic arms, automated production lines, digital twin holograms
- Semiconductor wafer/chip close-up with circuit patterns and data streams
- Display panel motif (OLED/microLED style glow gradients)
- Secondary battery cross-section iconography (cell, module, pack) with energy flow lines
- Abstract AI network mesh connecting all sectors

Korean typography (important):
- Main title text (large, centered): "GPT로 배우는 산업별 AI 실전 교육"
- Subtitle text (smaller): "제조업 · 반도체 · 디스플레이 · 2차 전지"
- Optional badge: "2026 Edition"
- Text must be crisp, correctly spelled Korean, no gibberish, no broken characters

Quality constraints:
- High detail, sharp focus, presentation-ready, clean negative space for lecturer name/logo
- Avoid clutter, avoid random English words, avoid watermark, avoid distorted hands/faces
- No brand logos of real companies

Output:
- One polished hero image suitable for lecture intro slide
- 4K feel, professional conference visual quality
```

```text

요구사항:
- 분위기: 신뢰감, 미래지향, 임원/실무자 교육에 적합한 고급스러운 톤
```
